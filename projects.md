## Project 1: Blog Management System

- **Problem:** Managing blog posts, categories, and images efficiently can be difficult without a centralised application.
- **Solution:** Developed a full-stack web application to create, view, update, and delete blog posts and manage categories and images.
- **Technologies:** Angular, ASP.NET Core Web API, PostgreSQL, Entity Framework Core, JWT, Cloudinary.
- **My contribution:** Worked on frontend development, API integration, authentication, and database operations.
- **What I learned:** Full-stack development, REST API integration, database management, and secure authentication.
- **Future improvement:** Add blog search, comments, and analytics features.

## Project 2: IoT-Based Intelligent Fire and Smoke Detection System

- **Problem:** Delayed detection of fire and smoke can cause safety risks and property damage.
- **Solution:** Planning an IoT-based system to monitor smoke, temperature, humidity, and flame conditions and provide alerts when potential fire hazards are detected.
- **Technologies:** IoT sensors, microcontroller, Machine Learning, buzzer, LED, and IoT notifications.
- **My contribution:** Working on project planning, system workflow design, and exploring sensor integration.
- **What I learned:** IoT system design, sensor-based monitoring, and the role of Machine Learning in intelligent detection.
- **Future improvement:** Implement the system, test it with real sensor data, and evaluate its detection accuracy.
